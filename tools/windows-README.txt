Crackdown Recomp (Windows x64)

Requirements: x64 CPU with AVX2 and FMA3, a D3D12 GPU, Windows 10/11 and the
Microsoft Visual C++ x64 Redistributable.

Run CrackdownRecomp.exe (app launchers such as Quiver start it for you).
The first time, choose INSTALL GAME and select your own Crackdown files: the World
multi-language disc, as an ISO (full XGD2 or trimmed XISO) or a folder with the
extracted disc. Supported default.xex SHA256:
7aaa7a8920d1c3c737e58cf583debafe6013be0a96bec3ec136e5de7e3377e5a
Every disc file is checked. The game files go to cd1\game.

Optional, from your own Xbox 360 (or a backup of its Content folder):
  - INSTALL DLC takes a DLC package from Content\0000000000000000\4D5307DC\00000002
    (keep its original file name). The Four-Play Pack works with the original game.
  - The Free-For-All Pack (Keys to the City, Street Racing) needs Title Update #6:
    INSTALL TITLE UPDATE takes TU_16L61US_0000004000000.00000000001G1 from
    Content\0000000000000000\4D5307DC\000B0000. It goes to cd1\tu.

Settings, save profiles, co-op and Archipelago are in the launcher. 60 fps is the
default. Saves and the shader cache go to Documents\crackdown (an empty
cd1\portable.txt keeps them in cd1\userdata instead).

Bug reports: include the latest cd1\logs\crackdown_NNN.log, cd1\VERSION.txt, what
happened and how to reproduce it.

Third-party notices are in LICENSES and cd1\LICENSES. Source and releases:
https://gitlab.com/pacific-city-recompiled/crackdown-recomp
Launcher source: https://gitlab.com/pacific-city-recompiled/launcher
